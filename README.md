# 🐸 Sapao.io

Um mini game arcade de arena inspirado na ideia de jogos `.io`, mas com um sapo como protagonista.

## Tecnologias
- HTML5
- CSS3
- JavaScript puro (ES6+)
- Canvas API
- LocalStorage para recorde

## Como jogar
Abra `index.html` no navegador.

**Controles:** WASD ou setas no PC. No celular, use os botões na tela.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub, por exemplo `sapao-io`.
2. Envie `index.html`, `style.css` e `script.js`.
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/root`.
4. Salve e abra o endereço do GitHub Pages.
